# Research Terminology

## Application Agent

An AI agent that performs an enterprise business function such as complaint analysis, employee-performance analysis or after-sales service intelligence.

## Security Agent

An AI/software agent that evaluates security-relevant events or behaviours.

## Compromised Security Agent

A security agent whose decisions or behaviour are no longer reliable because of attack, manipulation, abnormal behaviour, model failure or other controlled experimental conditions.

## Self-Attestation

Software-level behavioural verification of a security agent using controlled challenges and observed performance.

This does not refer to hardware-based remote attestation.

## Trust Score

A dynamic numerical representation of the estimated reliability of a security agent.

The trust score will be derived from behavioural and verification evidence rather than being manually assigned as a permanent value.

## Adaptive Trust

A mechanism where the estimated reliability of a security agent changes when new behavioural evidence becomes available.

## Equal Majority Voting

A baseline where every security agent has equal voting power.

## Trust-Weighted Decision

A decision mechanism where the contribution of each security agent depends on its current estimated trust.

## Quarantine

Temporary removal or restriction of a suspicious security agent from security-decision participation.

## Human Escalation

Routing an uncertain or high-risk security situation to an authorized human reviewer.

## System Resilience

The ability of the security framework to continue producing correct security decisions when one or more security agents become unreliable or compromised.
