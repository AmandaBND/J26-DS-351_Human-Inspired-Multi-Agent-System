# Emotion-Aware After Sales Service Decision Intelligence Agent

The Emotion-Aware After Sales Service Decision Intelligence Agent is a hierarchical multi-agent decision-support system designed to support after-sales service decision-making.

The system combines three main sources of information:

- Customer voice-derived affective signals
- Conversational context from call transcripts and textual feedback
- After-sales operational data such as service history, breakdown records, technician comments, and customer feedback

Specialized agents analyze each information source, and a Context Fusion Agent combines the results to create a unified understanding of the customer and service situation.

Analytical agents then identify service risks, customer priorities, root causes, and contributing factors. A Supervisor Agent uses this evidence to generate an explainable service recommendation together with supporting evidence and confidence information.

The system follows a Human-in-the-Loop approach, where an authorized Area Coordinator or manager can review, accept, modify, or reject the generated recommendation before an important service action is taken.

## Main Components

- Voice Emotion Analysis Agent
- Text Context Analysis Agent
- Operational Context Agent
- Context Fusion Agent
- Analytical Agents
- Supervisor Agent
- Human-in-the-Loop Review and Feedback Mechanism

## Research Focus

The main research focus is to investigate whether combining voice-derived affective information, conversational context, and after-sales operational evidence can provide more context-aware and explainable service decision support than approaches using only operational or textual information.
